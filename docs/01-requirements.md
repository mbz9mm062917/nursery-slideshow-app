# 要件整理

## 1. プロジェクトの目的

保育士が日々撮影する行事・保育活動の写真を、専門知識がなくても簡単にスライドショー動画へ変換し、
保護者へ配布できるようにする。

**コンセプト**: 「動画編集ソフト」ではなく「写真を選ぶだけで完成する、おまかせ動画生成ツール」。

## 2. ターゲットユーザー特性と設計への反映

| ユーザー特性 | 設計上の対応 |
|---|---|
| PC操作に不慣れ | 専門用語を避けたラベル、大きいボタン、アイコン主体のUI |
| 業務多忙・短時間で完了させたい | ウィザード形式（1画面1目的）で迷わない導線 |
| 大量の写真を扱う（100〜300枚） | 複数選択・ドラッグ＆ドロップ、サムネイル遅延読み込み、軽量な並び替えUI |
| 動画編集の専門知識がない | テーマ選択のみで見栄えが整う「お任せ」設計、生成前プレビューで安心感 |

## 3. MVP機能一覧

| # | 機能 | 概要 |
|---|---|---|
| ① | ホーム画面 | 「新しいスライドショー作成」導線のみ |
| ② | 写真アップロード | 複数選択・DnD・プレビュー（jpg/jpeg/png） |
| ③ | 写真並び替え | ドラッグ操作で順序変更 |
| ④ | タイトル入力 | 動画冒頭に表示するテキスト |
| ⑤ | テーマ選択 | シンプル／かわいい／卒園式／運動会（フレーム・アニメーション・背景が変化） |
| ⑥ | BGM選択 | 数曲から選択（明るい／感動／元気） |
| ⑦ | スライド時間 | 3秒／5秒／7秒 |
| ⑧ | プレビュー | 生成前に構成を確認 |
| ⑨ | 動画生成 | FFmpegでMP4を生成 |
| ⑩ | ダウンロード | 生成動画の取得 |

## 4. 非機能要件

- レスポンシブ対応（PC優先、タブレット対応）
- 動画生成中は進捗表示（＝非同期処理が前提になる）
- 写真100〜300枚程度を扱える性能
- エラー時はわかりやすいメッセージ
- 保守性・拡張性（テーマ・BGM追加を容易に）
- 型安全性（TypeScript strict / Javaの型システムを活用）

## 5. MVPでは実装しないが、設計上考慮する機能

将来追加された際にアーキテクチャの手戻りが起きないよう、以下の観点だけ設計に織り込む（実装はしない）。

| 将来機能 | 設計上の配慮 |
|---|---|
| AI編集・AIによる写真選択 | 写真選定ロジックをフロント/バック双方でサービス層として分離し、将来「自動選定サービス」に差し替え可能に |
| テロップ・字幕・ナレーション | スライド単位のメタデータテーブルに将来カラム（caption等）を追加できる正規化設計 |
| QRコード共有・保護者向けページ・クラウド保存・認証 | 「配布（Distribution）」ドメインを別モジュールとして後付けできるよう、現状のダウンロードAPIと責務を分離 |

## 6. 制約・前提

- MVPでは認証機構を持たない（プロジェクトはUUIDで匿名管理）
- 生成物（写真・動画）はサーバーのローカルストレージに保存（将来クラウドストレージへ差し替え可能な抽象化を行う）
- FFmpegはサーバー環境にインストール済みであることを前提とする
